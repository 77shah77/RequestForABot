# Мини-приложение для записи клиентов

## Описание
Веб-приложение на Flask для записи клиентов на услуги с админ-панелью.

## Возможности

### Для клиентов:
- ✅ Форма онлайн-записи на услугу
- ✅ Выбор услуги, даты и времени
- ✅ Указание контактных данных
- ✅ Добавление комментария к записи
- ✅ Адаптивный дизайн (работает на мобильных)

### Для администратора:
- ✅ Защищённая паролем админ-панель
- ✅ Просмотр всех записей
- ✅ Изменение статуса записи (ожидает/подтверждено/отменено)
- ✅ Удаление записей
- ✅ Статистика по записям

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте в браузере:
- Клиентская часть: http://localhost:5001
- Админ-панель: http://localhost:5001/admin/login

## Данные для входа в админ-панель

- **Логин:** `admin`
- **Пароль:** `admin123`

⚠️ **Важно:** В продакшене обязательно измените логин и пароль в файле `app.py`!

## Структура проекта

```
/workspace
├── app.py                 # Основной файл приложения
├── requirements.txt       # Зависимости
├── templates/            # HTML-шаблоны
│   ├── index.html        # Страница записи
│   ├── login.html        # Вход в админку
│   └── admin.html        # Админ-панель
└── instance/
    └── appointments.db   # База данных SQLite
```

## Технологии

- **Backend:** Python + Flask
- **Database:** SQLite + SQLAlchemy
- **Frontend:** HTML5 + CSS3 (без JavaScript-фреймворков)

## Настройка услуг

Откройте `templates/index.html` и измените список услуг в секции `<select id="service">`:

```html
<option value="Ваша услуга">Название услуги</option>
```
